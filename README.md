# SentimentAnalysis

This project was originally developed on Kaggle. Please visit https://www.kaggle.com/code/arewaiyi/i-have-a-dream-sentiment-analysis for a full contextual look.

## Summary of Project
The purpose of this project is to analyze the sentiment of Dr. Martin Luther King's "I Have A Dream" Speech. The TextBlob API was used to perform analysis, using the sentiment features subjectivity, and polarity.
